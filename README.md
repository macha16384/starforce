AIの勉強がてら、プログラミング経験が全く無い私が、AI（Gemini）のプログラマーになったもらい、ゲームを作ってみました。
最初は、ゼビウス風の物を作成しようと思い、作成し始めましたが、AIに指示の出し方が悪いのか、とりあえず、「ゼビウス風かな～？」レベルの物が出来上がったのですが、
その後、ブラッシュアップが上手く行かず、試行錯誤！「365歩のマーチ」（古）の歌詞ではありませんが、1歩進んで2歩戻る状態でした。
たまたま、同じ様にAIでゲームを作れている方が動画をアップされているのを発見し、動画を拝見し、その方の手順を参考にして、まずは、スターフォース風のゲームから作成してみました。
実際のスターフォースに近づけて作ってみましたが、敵の動き等、なかなか、上手く行きませんが、一応、私的には、公開出来るかな～って思いアップしました。
実際のスターフォースとの相違点※あくまでも「風」なので、全て、違うのですが…
・カルデロン及びパーサーは実装しておりません。※但し、レーザーがダブルになります。見つけてください。
・敵の攻撃力（難易度）を下げることが出来ます。※見つけてください。
・シークレットは設定していませんが、代わりの隠れキャラ的な物があります。
・50万点で1UP、その後は、200万点※以降200万点加算で1UP
・クレオパトラも未実装です。
